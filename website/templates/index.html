Welcome to Predictive Maintenance

This system analyzes real-time operational telemetry parameters (air temperature, process temperature, rotational speed, torque, and tool wear) to predict whether an industrial machine is likely to experience a failure.

The system utilizes machine learning classifiers developed during the Data Mining laboratory experiments.
